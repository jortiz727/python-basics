# Python Basics

A collection of beginner-to-intermediate Python projects I built to learn the language by making real, working programs. Each project lives in its own folder.

## Projects

| Project | What it does | Concepts practiced |
|---|---|---|
| [2048_Game](./2048_Game) | A version of the 2048 sliding-tile puzzle game | Game logic, lists/grids, functions |
| [calculator](./calculator) | A calculator that performs basic math operations | User input, functions, error handling |
| [file_sorter](./file_sorter) | Sorts files into folders automatically | File handling, `pathlib`/`os`, loops |
| [hangman_Game](./hangman_Game) | A word-guessing game of Hangman | Strings, loops, conditionals |
| [rps_game](./rps_game) | Rock, Paper, Scissors against the computer | Randomness, conditionals, loops |

Also in this repo:
- `helloworld.py`: my first Python script
- `notes.md`: notes I took while learning

## How to run a project

1. Install [Python 3](https://www.python.org/downloads/).
2. Clone the repo:
   ```
   git clone https://github.com/jortiz727/python-basics.git
   ```
3. Open a project folder and run its main file:
   ```
   cd python-basics/hangman_Game
   python main.py
   ```
   (Replace `main.py` with the file name inside that folder.)
